# Arnex Tech — React Website

## 🚀 Setup & Run

```bash
# Install dependencies
npm install

# Start development server
npm start

# Build for production
npm run build
```

## 📁 Project Structure

```
arnex-tech/
├── public/
│   └── index.html
├── src/
│   ├── components/
│   │   ├── Navbar.jsx      # Fixed navigation with smooth scroll
│   │   ├── Hero.jsx        # Hero section with animated particles
│   │   ├── Ticker.jsx      # Scrolling marquee strip
│   │   ├── Services.jsx    # 6 IT service cards
│   │   ├── About.jsx       # Company info + timeline
│   │   ├── Process.jsx     # 5-step process
│   │   ├── Contact.jsx     # Contact form + info
│   │   └── Footer.jsx      # Footer with links
│   ├── App.jsx             # Main app component
│   ├── index.js            # React entry point
│   ├── index.css           # Global styles & CSS variables
│   └── logo.js             # Logo image (base64)
├── package.json
└── README.md
```

## 🌐 Deploy on Vercel (Free)

1. Push code to GitHub
2. Go to vercel.com → Import project
3. Deploy! ✅

## 🎨 Tech Stack
- React 18
- CSS Variables (no extra CSS library)
- Google Fonts (Rajdhani + Exo 2)
